# Figures

This folder contains figures generated by the project analysis.

Planned figures include:

- Loan and charge-off counts by lending cohort
- Charge-off rates by lending cohort
- Distributions of continuous predictors
- Charge-off rates across categorical predictors
- Model-discrimination plots
- Calibration plots
- Threshold-specific classification comparisons

Figures will use sequential and descriptive filenames, such as:

- `figure_01_cohort_counts.png`
- `figure_02_chargeoff_rates.png`
- `figure_03_gross_approval_distribution.png`

Each figure will be generated reproducibly using the scripts in the
`code` directory and referenced in the interim or final report.
