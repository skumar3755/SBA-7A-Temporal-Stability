# Outputs

This directory contains tables, figures, and analytical outputs generated from the reproducible analysis workflow.

Outputs will be organized according to the four research questions:

- RQ1 — Approval-time credit-risk factors
- RQ2 — Temporal stability of credit-risk factors
- RQ3 — Out-of-time predictive stability
- RQ4 — Risk classification performance

Generated outputs will be stored separately from the source and processed datasets.
