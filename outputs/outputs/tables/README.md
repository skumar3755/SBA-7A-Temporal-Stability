# Tables

This folder contains analytical tables generated by the project code.

Planned outputs include:

- Data-quality summaries
- Missing-value summaries
- Eligibility and exclusion counts
- Cohort and outcome summaries
- Descriptive statistics
- Logistic-regression results
- Model-performance comparisons
- Threshold-specific classification metrics

Tables will use sequential and descriptive filenames, for example:

- `table_01_data_quality.csv`
- `table_02_cohort_summary.csv`
- `table_03_rq1_logistic_results.csv`
