# Processed Data

This folder will contain the analysis-ready dataset generated by the
documented data-cleaning and cohort-construction workflow.

The processed data will include:

- Eligible SBA 7(a) loan records
- The derived 36-month charge-off outcome
- Chronological cohort assignments
- Selected approval-time predictors
- Documented categorical coding
- Missing-value indicators where required

Outcome-revealing variables and unnecessary borrower identifiers will
not be retained in the predictive feature set.

The processed dataset will be generated from the raw source data using
the scripts provided in the `code` folder.
